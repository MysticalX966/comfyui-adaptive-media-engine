# Contributing

Contributions are welcome.

For workflow-profile contributions:

1. Do not include model weights.
2. Do not include credentials or private URLs.
3. Do not include machine-specific absolute paths.
4. Prefer API workflow templates over UI workflow JSON.
5. Document required models and custom nodes.
6. Mark untested profiles as `NEEDS_SETUP` or `TESTING`, never `READY`.
7. Preserve last-known-good workflow versions.
